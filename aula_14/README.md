## API Casa de Sucos

# Descrição

Este projeto consiste no desenvolvimento de uma API para uma Casa de Sucos, utilizando Python e FastAPI. A aplicação consulta a API pública Fruityvice para obter informações nutricionais das frutas, como calorias e quantidade de açúcar.

A API permite consultar frutas, cadastrar sucos com suas respectivas frutas e informações nutricionais, além de listar os sucos cadastrados.

# Tecnologias utilizadas

- Python

- FastAPI

- Uvicorn

- Requests

- Fruityvice API

# Funcionalidades

Consultar informações nutricionais de uma fruta.

Retornar mensagens de erro para frutas não encontradas.
